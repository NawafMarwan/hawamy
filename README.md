# الموقع الرسمي لمجمع حلقات جامع الحوامي

موقع ثابت (HTML / CSS / JavaScript) بلا أي مكتبات خارجية، يُستضاف مجانًا على **GitHub Pages** بالنطاق **www.hawamy.org**.

## هيكل الملفات

```
index.html            الصفحة الرئيسية (التعريف، الرؤية والرسالة، المنجزات، التواصل، الدعم)
achievements.html     صفحة الإنجازات والدروع (خط زمني + تصفية)
media.html            صفحة المحتوى المرئي (ألبومات حسب السنة/المناسبة + يوتيوب + عارض)
404.html              صفحة «غير موجودة»
data/achievements.js  ← بيانات الإنجازات (تُعدَّل هنا فقط)
data/media.js         ← بيانات الألبومات والمقاطع (تُعدَّل هنا فقط)
assets/css/main.css   التصميم والحركات
assets/js/            السكربتات (التاريخ الهجري، العارض، الحركات…)
assets/img/           الشعار والصور
assets/fonts/         خط Cairo (مستضاف محليًا)
CNAME                 ربط النطاق www.hawamy.org
```

## إضافة محتوى

### إنجاز أو درع جديد
1. ضع الصورة في `assets/img/achievements/` (يفضَّل WebP بعرض لا يتجاوز 1600px).
2. افتح `data/achievements.js` وانسخ عنصرًا موجودًا، ثم عدّل: `title`، `issuer`، `year`، `date`، `category`، `description`، `images`.
3. يُرتَّب الإنجاز تلقائيًا حسب السنة، وتظهر أزرار التصفية من تلقاء نفسها إذا تعددت التصنيفات.

### ألبوم صور أو مقطع يوتيوب
1. ضع الصور في `assets/img/media/<اسم-الألبوم>/`.
2. افتح `data/media.js` وأضف ألبومًا: `title`، `occasion`، `year`، `date`، `cover`، `items`.
3. مقطع يوتيوب: `{ type: "youtube", id: "xxxxxxxxxxx", caption: "..." }`، والمعرّف هو ما بعد `v=` في الرابط.

> **ملاحظة:** بعد أي تعديل على ملفات CSS/JS، ارفع رقم `?v=1` في روابط الصفحات حتى تظهر التحديثات فورًا للزوار.

## ربط النطاق hawamy.org بالمستودع

### 1) تفعيل GitHub Pages
1. ادمج فرع العمل في الفرع `main`.
2. في المستودع: **Settings ← Pages**.
3. **Source:** `Deploy from a branch`، ثم **Branch:** `main` والمجلد `/ (root)`، ثم **Save**.
4. في خانة **Custom domain** اكتب: `www.hawamy.org` ثم **Save** (الملف `CNAME` موجود مسبقًا).

### 2) إعدادات DNS عند مزوّد النطاق
احذف أي سجلات قديمة لـ `@` و`www`، ثم أضف:

| النوع | الاسم (Host) | القيمة |
|---|---|---|
| `CNAME` | `www` | `nawafmarwan.github.io` |
| `A` | `@` | `185.199.108.153` |
| `A` | `@` | `185.199.109.153` |
| `A` | `@` | `185.199.110.153` |
| `A` | `@` | `185.199.111.153` |
| `AAAA` | `@` | `2606:50c0:8000::153` |
| `AAAA` | `@` | `2606:50c0:8001::153` |
| `AAAA` | `@` | `2606:50c0:8002::153` |
| `AAAA` | `@` | `2606:50c0:8003::153` |

بهذه الإعدادات يحوّل GitHub الزائر تلقائيًا من `hawamy.org` إلى `https://www.hawamy.org`.
قد يستغرق انتشار DNS من دقائق إلى 24 ساعة.

### 3) تفعيل HTTPS
بعد أن يظهر في صفحة Pages أن الفحص نجح (DNS check successful)، فعّل الخيار **Enforce HTTPS**.

### 4) توثيق النطاق (حماية من سرقة النطاق)
**صورتك الشخصية ← Settings ← Pages ← Add a domain** ← اكتب `hawamy.org`. سيعطيك GitHub سجل `TXT` تضيفه في DNS، ثم اضغط **Verify**.

## الظهور في جوجل بصيغة www.hawamy.org
تم تجهيز ما يلزم داخل الموقع مسبقًا:
- وسم `canonical` في كل صفحة يشير إلى `https://www.hawamy.org/...`.
- ملفا `sitemap.xml` و`robots.txt`.
- بيانات منظَّمة (Schema.org: EducationalOrganization).
- وسوم المشاركة (Open Graph)، ومعها صورة تظهر عند مشاركة الرابط في واتساب وتويتر.

المطلوب منك:
1. افتح [Google Search Console](https://search.google.com/search-console) وأضف خاصية من نوع **Domain** للنطاق `hawamy.org`، ثم وثّقها بسجل `TXT` في DNS.
2. من قائمة **Sitemaps** أرسل: `https://www.hawamy.org/sitemap.xml`.
3. من **URL Inspection** افحص `https://www.hawamy.org/` واطلب الفهرسة (Request Indexing).
4. يُنصح بإنشاء ملف تجاري للمسجد في **Google Business Profile** وربطه بالموقع، حتى يظهر المجمع في نتائج الخرائط.

## الأمان
ما تم تطبيقه:
- **سياسة أمان المحتوى (CSP):** لا يُسمح بتشغيل أي سكربت أو تحميل أي ملف إلا من الموقع نفسه، والاستثناء الوحيد هو يوتيوب (نسخة `youtube-nocookie`).
- لا توجد مكتبات أو خطوط أو أدوات تتبّع من جهات خارجية، فلا تأتي ثغرات من طرف ثالث.
- منع تضمين الموقع داخل مواقع أخرى (Clickjacking)، ومعه `noopener noreferrer` لكل الروابط الخارجية.
- كل البيانات تُعرض عبر `textContent`، وهذا يحمي من حقن الشيفرات (XSS).
- **حماية الصور:** منع القائمة اليمنى والسحب وحفظ الصور بالضغط المطوّل في آيفون، ومنع طباعة الصور.
  هذه الحماية **تُصعِّب** التنزيل ولا تمنعه منعًا تامًا، إذ لا يوجد موقع يستطيع منعه كليًّا. لمزيد من الحماية يمكن رفع الصور بعلامة مائية خفيفة.
- ملف `/.well-known/security.txt` للإبلاغ عن الثغرات.

توصيات مهمة لك:
- فعّل **التحقق بخطوتين (2FA)** في حساب GitHub، وفي حساب مزوّد النطاق كذلك.
- فعّل **DNSSEC** من لوحة مزوّد النطاق إن كان متاحًا.
- **لا ترفع أبدًا بيانات الطلاب أو التقارير الخاصة إلى هذا المستودع.** المستودع العام وكل ملفاته متاحة للجميع.

## المرحلة القادمة: صفحات بتسجيل دخول
GitHub Pages يستضيف ملفات ثابتة فقط، ولا يوفر تسجيل دخول حقيقيًا. أي «كلمة مرور» تُكتب داخل الصفحة يمكن تجاوزها بسهولة. عند الحاجة إلى صفحات خاصة (المناهج، التقارير، بيانات الطلاب) فالخيارات الآمنة:
1. **Cloudflare Access:** مجاني حتى 50 مستخدمًا، ويحمي مسارًا مثل `/portal` ببريد إلكتروني ورمز تحقق. يتطلب نقل DNS إلى Cloudflare.
2. **Supabase أو Firebase:** تسجيل دخول وقاعدة بيانات بصلاحيات لكل مستخدم، ومناسب لبيانات الطلاب.
